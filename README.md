# QuestDock V1.0 · 人生任务栏

This is a Quest Manager that can manage all your quest like games.

公开发行版首次启动没有预置任务，可自行创建任务；保留默认任务类型与通用商店商品。已有用户升级时继续读取本机存档，不清空任务、奖励和设置。安装包不包含个人存档。

版本号为 `1.0.0`，本版作为后续开发的基线。正式安装包按 `releases/v版本号/` 分目录保存，不覆盖历史版本。开发与发布约定见 DEVELOPMENT.md。

版本更新：设置 → 版本与更新，默认使用公开仓库 https://github.com/anayse/QuestDock 。可以手动检查，或开启“自动检查并下载新版”（默认关闭，开启后启动时及每 6 小时检查）。下载在后台进行；校验文件大小与 SHA-256 后，点击“安装并重启”并确认才替换程序。任务存档保留，原程序备份为 `QuestDock.previous.exe`。源码运行模式不自动替换 Python 文件。仓库尚无正式 Release 时会提示暂不可用。

新版采用紧凑深色界面：紫色强调色、56 像素悬浮球、任务进度和代币余额。面板采用无系统白色标题栏的自绘窗口，保留右上角退出、悬浮球右键退出与 Ctrl+Q / Alt+F4。拖动顶部移动，右下角手柄调整尺寸。

本次优化：搜索标题与描述（Ctrl+F）、隐藏已完成任务、紧凑卡片、可拖动滚动条、PageUp/PageDown/Home/End 列表导航、Ctrl+Enter 保存任务。窗口大小与筛选偏好自动保留，展开与收起不再播放动画。

今日清单与专注：

- 在任务卡片点“＋ 今日”，可把每日、作业、科研等任务混合加入今天的计划；“今日”分类只显示这些任务。再次点击即可移出。跨日清除手动选择，并按任务类型规则自动加入今日；保留非每日任务的进度。
- 顶部和悬浮球仅统计今日清单，未选择任务时显示 0/0，不再回退到每日任务。
- 在现有任务详情中点“保存并专注”，保存修改并启动 25 分钟计时。面板底部可暂停、继续或结束；悬浮球同步显示剩余时间。
- 计时结束发出提示音并记入冒险记录，不自动推进任务、判定完成或发放代币。
- 正常退出后恢复为暂停状态。运行中每分钟保存一次计时检查点；异常退出最多可能丢失最近一分钟的计时。检测到超过 15 秒的回调中断（如系统休眠）时自动暂停，不把中断时间计入专注。
- 没有运行中的计时器时，不增加每秒后台回调。运行中仅更新计时文本，不重画整个面板。

操作便利性更新：

- 调整任务进度后，10 秒内可点击提示中的“撤销”，或在任务面板按 Ctrl+Z。仅撤销最近一次进度调整；领取奖励、日期变化或任务状态变化后不再撤销，编辑框里的 Ctrl+Z 不受影响。
- 有待领取奖励时，顶部显示“领取全部”。确认后领取所有分类中的已完成任务奖励，不受搜索和筛选限制，每项只领取一次。
- 商店卡片支持直接编辑名称和价格，已兑换的奖励券保留原名称。
- 长标题根据实际显示宽度截断，完整内容可在任务详情中查看。
- 表单内容支持滚动，Tab 切换到下方控件时自动滚动到控件位置；保存／确认按钮固定在底部，缩小窗口仍可操作。

桌面工作模式：

- 默认面板 380×600，可缩小至 360×460；任务列表占主要空间。尺寸使用 Windows 逻辑像素，随系统缩放显示。
- 悬浮球拖到主屏幕边缘 32 像素以内会吸附，停留约 0.9 秒后收起，仅露出 16 像素；鼠标移入恢复。设置中可关闭自动收起。当前贴边以主显示器为范围。
- 底部“锁定位置”同时锁定悬浮球、面板位置和面板大小；再次点击即可解锁，重启后保留。
- 透明度过低时，鼠标移入悬浮球会临时提高可见度。右键选择“恢复默认显示”可恢复 95% 不透明度和默认面板大小；应用获得焦点时也可按 Ctrl+Shift+R。

性能：拖动悬浮球合并为每 16 毫秒至多一次位置更新；拖动透明度滑块不重绘任务列表，松手才保存；相同存档不重复读写磁盘。按钮悬停只更新按钮颜色；高频滚动与尺寸变化合并绘制；只绘制列表可见部分；悬浮球后台不再持续播放动画。

退出方式：点击任务面板的 ×、按 Ctrl+Q / Alt+F4，或右键悬浮球选择退出。横线和 Esc 仅收起面板。弹窗不再锁定其他窗口的输入。退出时即使最后一次保存失败也会关闭程序，错误会写入存档目录的 exit-error.log。

- 悬浮球显示今日清单完成数量，有待领取奖励时出现角标。
- 点击悬浮球立即展开，顶部可拖动面板，右上角横线或 Esc 收起。
- 顶部齿轮打开贴边自动收起、位置锁定和置顶设置；右键悬浮球可以恢复默认显示或完全退出。
- 任务卡片支持追踪并优先显示，点“详情”查看或编辑完整描述。
- 分类切换每日、剧情、科研与支线任务；多目标任务按进度自动获得代币，单目标任务完成后领取，界面显示即时反馈。
- 商店、背包、冒险记录与任务表单使用一致的视觉风格。
- Ctrl+N 快速创建任务。滚轮浏览任务列表。
- 兼容旧版存档；覆盖安装前先退出旧版。

Windows 桌面悬浮任务系统。解压安装包后双击 Install.cmd 安装，不需要管理员权限或 Python。也可直接运行 QuestDock.exe。

- 启动后只显示桌面悬浮球。拖动悬浮球移动，单击展开或隐藏任务栏。
- 任务栏在悬浮球旁展开，可拖动顶部移动；高度根据屏幕自动适配。
- 底部常驻不透明度滑块（1–100%）：1% 几乎透明，100% 完全不透明，同时调节悬浮球和任务栏，松手保存。
- 点击横线或按 Esc 隐藏任务栏；关闭按钮彻底退出。右键悬浮球可打开设置、恢复默认显示或退出。
- 自定义任务标题、类型、目标次数、描述和代币奖励。
- 每日任务在本地日期变化后重置；其他任务持续保留。
- 多目标任务每次推进自动结算代币与 XP，每个进度只结算一次；单目标任务完成后仍手动领取。
- 科研任务可自行设置目标次数和里程碑说明。
- 商店商品可新增和下架，兑换后在背包使用奖励券。
- 商品仅代表个人约定的奖励，不会自动转账或购买游戏资金。

存档：`%APPDATA%\QuestDock\save.json`。重新安装不会覆盖存档。每次内容变化时，上一版有效 JSON 留在 `save.bak`。保存失败时底部显示重试入口，并在 `save-error.log` 记录错误。恢复备份前先退出程序并保存现有文件副本。

新版通过进程锁防止重复启动后同时覆盖存档。升级前需要退出旧版本（旧版本没有此机制）。

通过 Install.cmd 安装后，会注册到 Windows 设置 → 应用 → 已安装的应用，显示名称与版本，可从此处卸载。安装仅针对当前用户，不需要管理员权限。直接运行便携 EXE 不会注册。卸载前先退出程序；卸载保留个人存档。此版本尚未购买代码签名证书，Windows 可能显示未知发布者提示。

开发：Python 3.12+，先 `python -m pip install Pillow`，运行 `python premium.py` 或 `python app.py`。

构建：先 `python -m pip install -r requirements-build.txt`，再 `python release.py`。输出包含更新安装脚本的 EXE、安装 ZIP 和 SHA-256 清单。

验证：`python -m unittest test_desktop_geometry test_desktop_shell test_focus_timer test_premium test_activity -v`（使用独立临时存档）。

性能验证：`python benchmark_ui.py`，结果保存在 `test-output/performance.json`。数据是本机测量，不能代表所有设备。

每日刷新与完成日历：

- 按电脑本地日期检查跨日（后台每 30 秒检查，重新展开面板时立即检查）。关闭期间跨日，下次启动也会刷新。
- 跨日前保存每日任务完成记录，再将每日进度和领奖状态清零；剧情与科研任务保留进度。
- “日历”页支持周、月、自定义日期区间。周视图从周一到周日；月视图按自然月显示；自定义输入起止日期（包含两端），长区间以每页 20 周的热力图展示。左右箭头翻周、翻月或翻页；点击日期查看完成任务。颜色代表当天达到目标的每日任务数量，领奖不重复计数；当天撤销完成会同步撤销计数。
- 自定义区间直接在日历页显示起止日期框；点击后在框下展开无边框日历，可切换年/月或选择今天，选好后点击“应用”。点击外部或按 Esc 收起。开始晚于结束会提示修正，最近使用的模式和区间会保留。
- 历史完成记录随存档保留；升级前未记录的日期显示为未知，不从缺少年份的旧日志推测打卡。
- 悬浮球采用 4 倍超采样图标与 Windows 逐像素透明合成，保留圆形边缘的半透明像素，避免颜色键裁切造成的毛边。绘图结果缓存，无持续动画。
- 不透明度使用自绘细轨道和紫色圆形滑钮，支持鼠标拖动、方向键每次 1%、Home/End 到 1%/100%；拖动时实时预览，松手保存。

任务类型与今日清单：

- 默认名称为每日任务、剧情任务、科研、支线探索；旧存档名称自动迁移，任务进度与代币保留。
- 设置 → 管理任务类型，可以添加类型、修改名称，并设置是否自动加入今日。已有任务随类型改名同步更新。
- 每日任务默认自动加入今日。手动移出当天不会马上被加回，下一天仍按类型规则加入。
- 自动加入今日不等于每日重置；原每日任务类型改名后仍每日重置，新建类型、剧情和科研保留进度。
- 类型筛选采用下拉菜单，添加更多类型不会挤压任务列表。
- 不透明度滑钮改为 4 倍超采样绘制，保持平滑圆边。

界面与等级：

- 任务编辑、商品编辑、确认框、类型管理、等级说明和启动提示使用无系统标题栏的深色窗口，保留关闭按钮与退出快捷键；编辑窗口可拖动顶部移动。
- 右上角代币与设置图标使用固定尺寸的抗锯齿图像，不依赖字体符号或 emoji 回退。
- 任务页显示等级经验条，点击经验条查看说明：领取任务奖励时，每 1 代币奖励同时计入 1 XP，每累计 200 XP 升一级。兑换商品不扣经验；专注计时不直接增加经验。

进度奖励与统一控件：

- 目标次数大于 1 时，奖励字段表示每次进度奖励。例如目标 3 次、奖励 30，则每次获得 30，合计 90 代币与 XP。
- 已结算进度不会重复发奖。减进度或撤销只修正进度，保留已发奖励；重复推进不再发奖。每日任务跨日重置结算标记。
- 旧版已经领奖的任务不补发；旧版尚未领奖的多目标进度在下一次推进或结算时按新规则一次性结算。
- 今日进度与等级使用同风格进度条；余额、任务卡与商店使用同一代币图标；信息图标使用抗锯齿图像。
- 表单采用无箭头细滚动条；无需滚动时不绘制滑块；下拉列表的滚动条也统一为细条。
