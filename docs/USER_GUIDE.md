# QuestDock 使用指南

[返回首页](../README.md) · [下载最新版](https://github.com/anayse/QuestDock/releases/latest)

## 安装与首次启动

下载 `QuestDock-Setup.exe`，或解压版本 ZIP 后打开其中的同名安装器。选择当前用户可写的目录，点击“安装”。两个下载入口使用完全相同的安装器。

安装会创建桌面和开始菜单快捷方式，并注册到 Windows“已安装的应用”。首次启动只显示悬浮球；点击后展开任务栏。公开版没有个人预置任务，需要自行发布。

当前安装器未进行代码签名，Windows 可能显示未知发布者提示。请核对下载来源为本仓库的 Releases。

## 任务、今日与类型

创建任务时填写标题、类型、描述、目标次数和奖励。可以在详情里修改或追踪任务，追踪项优先显示。

“今日”是当天的计划，不是另一种任务类型。每日、剧情、科研或自定义类型都能加入今日。设置中的“管理任务类型”支持添加、改名，并决定该类型是否自动加入今日。

- 每日任务默认自动加入今日；当天手动移出后不会马上被加回。
- 跨日清除上一天的手动计划，再按类型规则填充今日。
- 自动加入今日与每日重置是两个规则。原每日类型即使改名仍每日重置；新建类型默认保留进度。
- 悬浮球和顶部进度条只统计今日清单；没有计划时显示 0/0。

## 代币与等级

| 任务 | 奖励结算 |
| --- | --- |
| 目标为 1 次 | 完成后手动领取，也可使用“领取全部”。 |
| 目标大于 1 次 | 每推进一个未结算进度，自动获得该任务设置的代币与 XP。 |

例如目标 3 次、每次奖励 30，总奖励是 90 代币和 90 XP。每累计 200 XP 升一级；商店消费不会扣 XP。

已发奖励不因减进度或撤销而回收，重复推进也不会重复结算。每日任务在新一天清除当天的结算标记。旧存档中已领奖的任务不会重复补发。

调整任务后可在 10 秒内通过提示或 Ctrl+Z 撤销最近一次进度操作；领取奖励、跨日或相关状态改变后撤销入口可能失效。

## 商店与背包

在商店定义奖励名称与所需代币，兑换后可在背包使用奖励券。编辑商品不会修改已经兑换的券。游戏预算、休息券等只是你对自己的约定，程序不会进行支付或购买。

## 完成日历

日历支持自然周、自然月和自定义起止日期。点击自定义日期框可展开日期选择器，不必手动输入。长区间按每页 20 周展示。

颜色表示当天达到目标的每日任务数量；领奖不重复计数，当天撤销完成会同步修正记录。跨日检查约每 30 秒执行，展开任务面板时也会检查。关闭期间跨日，下次启动会处理。旧版本未记录的日期保持未知。

## 专注计时

在已有任务详情中选择“保存并专注”，启动 25 分钟计时。可以暂停、继续或结束。计时结束记入记录，但不自动推进任务或发奖。

正常退出后恢复为暂停状态。运行时每分钟保存一次检查点；异常退出可能丢失最近一分钟。检测到超过 15 秒的回调中断（例如系统休眠）时自动暂停，不把中断时间计入专注。

## 桌面与快捷键

拖动悬浮球靠近主屏幕边缘会吸附，停留后可自动收起；鼠标移入恢复。设置中可关闭自动收起或锁定位置。默认面板为 380×600，最小 360×460。

| 操作 | 快捷键 / 入口 |
| --- | --- |
| 创建任务 | Ctrl+N |
| 搜索 | Ctrl+F |
| 保存任务表单 | Ctrl+Enter |
| 撤销最近的进度操作 | Ctrl+Z |
| 浏览任务列表 | 滚轮、PageUp / PageDown / Home / End |
| 收起任务面板 | Esc 或标题区横线 |
| 退出 | Ctrl+Q、Alt+F4、面板 × 或悬浮球右键菜单 |
| 恢复默认显示 | Ctrl+Shift+R 或悬浮球右键菜单 |

不透明度为 1–100%。过低时，鼠标移入悬浮球会临时提高可见度；“恢复默认显示”会恢复 95% 不透明度与默认面板大小。

## 更新、迁移与卸载

自动更新默认关闭。在“设置 → 版本与更新”中开启后，启动时和之后每 6 小时检查公开的正式 Release。后台下载经过大小、SHA-256 与 EXE 文件头检查后，需要点击“安装并重启”并确认。替换前保留旧程序为 `QuestDock.previous.exe`。

V1.0/V1.1 到 V1.2 的首次升级请运行一次安装器；V1.2 使用独立更新组件，避免将安装器误当作应用本体。源码模式不会自动覆盖 Python 文件。

个人数据在 `%APPDATA%\QuestDock\save.json`，上一次有效备份为 `save.bak`。迁移到另一台电脑时，先退出两边的 QuestDock，备份目标机原文件，再复制存档。不要在应用运行时替换存档。

卸载前退出程序，然后在 Windows 设置的“已安装的应用”中卸载。卸载保留任务数据。需要更换安装目录时先卸载，再运行安装器选择新位置。

## 常见问题

**关闭面板后为什么还有悬浮球？** Esc 和横线用于收起。彻底退出请使用 ×、Ctrl+Q 或右键退出。

**为什么没选到安装位置？** V1.2 的下载入口应为 `QuestDock-Setup.exe`。早期 `QuestDock.exe` 是应用本体，不会显示安装界面。

**更新提示失败怎么办？** 先确认网络与仓库地址。更新替换失败不会主动删除旧程序；相关错误保存在更新缓存的 `update-error.log`。也可从 Releases 下载安装器，在退出应用后安装。

**为什么任务没有显示在今日？** 检查是否手动加入，或其类型是否设置为自动加入；当天手动移出的任务会尊重你的选择。
